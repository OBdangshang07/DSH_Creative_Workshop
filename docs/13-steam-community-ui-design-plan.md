# Steam Community 范式：DSH 创意工坊设计规划

> 目标对象：参照 [`https://steamcommunity.com/app/`](https://steamcommunity.com/app/) 经典游戏创意工坊（如 Steam 社区枢纽、Steam Workshop 浏览与订阅中心）的交互与信息架构体系。  
> 适用场景：将 DeepSeek Harness 的插件发现、评估、合集与一键挂载，完整映射为 Steam 玩家与开发者最熟悉的经典社区工坊体验。  
> 状态：设计规划方案（Steam Community 范式版）。

---

## 一、 产品定位与 Steam 概念映射

在 Steam 社区中，每个游戏（App）都有一个专属的 Community Hub 与 Workshop。我们将 DSH 视为宿主引擎（App），插件视为工坊物品（Workshop Items），Profile 视为订阅档案（Subscribed Profile）。

| Steam 原生概念 | DSH 创意工坊对应实体 | 界面与交互行为映射 |
|---|---|---|
| **App Community Hub** | DSH 社区枢纽总站 | 包含工坊、讨论区、指南、更新日志、API 文档的大顶栏 |
| **Workshop Item** | DSH 插件 Bundle / Package | 带有 16:9 封面、作者信息、评分、更新日志的标准物品卡 |
| **Subscribe (订阅)** | 一键安装并挂载到当前 Profile | 调用 Companion 执行 `dsh plugin add`，就地变为「已订阅」 |
| **Required Items (必需物品)** | Cordis `inject` 与 `requires` 依赖链 | 订阅盒上方醒目提示「此物品需要以下前置项才能运行」并支持一键补齐 |
| **Collections (合集)** | DSH Profile Bundle 有序预设 | 策展人创建的一揽子插件清单，提供「一键全部订阅」按钮 |
| **Subscribed Items** | 我的档案（已装列表） | 支持拖拽层序、批量更新、按 Profile 分类管理 |
| **Change Notes (改动历史)** | Release 版本史与提交记录 | 严格按版本查看每个 Release 的更新说明与兼容变化 |

```text
│     ├── 讨论区 (Discussions)

│     └── 5. 已订阅管理页 (Subscribed Items) —— 档案层叠管理 + 一键更新全部
```

#### 主页区块说明：
1. **Spotlight Carousel**：顶部大画廊，自动/手动切换 3~5 个经过严格兼容实测的精选 Bundle，右侧直接提供大尺寸「+ 订阅」绿色按钮；
2. **本周最热门 (Most Popular This Week)**：根据近 7 天用户评分与实测成功率排序，杜绝远古插件霸榜；
3. **最多人订阅 (Most Subscribed)**：历史累计挂载量最高的标杆插件（如 MCP Bridge、Workspace Inspect）；
4. **必备底座 (Most Required Items)**：对标 Steam Most Required，突出 Definition 与高频 Provider 服务；
5. **右侧工坊状态卡**：实时展示当前活跃 Profile、已订阅数量、待更新数量及 Companion 状态。

#### 详情页交互要点：
- **Steam 经典绿色大订阅按钮**：点击后触发安装事务，按钮文字平滑过渡为 `✓ 已订阅 (Subscribed)`，并伴随右上角当前 Profile 订阅计数 `+1`；
- **必需物品清单 (Required Items)**：以缩略图网格列出前置依赖，并在上方提供「一键全部订阅 (Subscribe All)」，一键解决依赖闭包；
- **环境绑定评价流**：每条评论显示该用户发表时绑定的 DSH 大版本号与运行模式（如 `[DSH 0.1.0-rc.5 · 标准模式]`），防止跨版本误导。

### 3. 合集页 (Collection Page)

合集对齐 Steam 的 Curated Collections，本质是一个不可变的 Bundle 安装包。

- **合集标题与大画廊封面**；
- **策展人说明**（解释该组合的适用场景，例如「全能全栈开发套件」）；
- **「一键全部订阅 (Subscribe to All)」主按钮**：
  - 点击后弹出事务确认，列出将要依次写入本地 Profile 的 Bundle 有序列表；
  - 自动检测并提示是否有与本地已有插件冲突的条目；
- **包含物品列表**：展示每件物品的封面、名称、作者与单独订阅开关。

---

### 4. 我的工坊文件 / 已订阅管理 (Subscribed Items)

对标 Steam 客户端中的工坊管理界面，管理本机事实：

- **Profile 筛选器**：支持在 `default-web`、`headless-agent`、`custom-sandbox` 间切换查看；
- **拖拽层序调整 (Layer Order)**：列表项支持拖拽排序（映射 `cordis.patch` 顺序）；
- **一键全部更新 (Update All)**：检测到有新版本的已订阅插件时，顶部出现醒目提醒并支持一键更新；
- **批量取消订阅 / 禁用**：支持单选/全选批量卸载。

## 五、 五大核心要求的 Steam 风格实现对照

| 核心要求 | Steam 范式设计落地 |
|---|---|
| **1. “一键式”极简交互** | 采用 Steam 经典绿色 `+ 订阅 (+ Subscribe)` 按钮，单次点击即完成事务；缺失依赖时弹出 Steam 经典的「必需物品全部订阅」确认框； |
| **2. 视觉主导与标准化** | 统一 16:9 标准媒体封面与左侧媒体画廊，右侧固定 12 键规格表与创作者信息盒，杜绝非结构化排版； |
| **3. 社区动态评价** | 采用 Steam 经典 5 颗星评分条与「好评如潮 / 特别好评 / 多半好评」等级划分，评价强绑定用户发表时的 DSH 大版本号； |
| **4. 精准标签与网状检索** | Steam 经典右侧分类标签复选框（形态、能力键、运行表面、来源渠道），支持点击任意标签直接展开关联网络； |
| **5. 依赖关系与合集直观化** | 在物品页与订阅盒中直接内嵌「必需物品 (Required Items)」网格，合集页支持「一键全部订阅 (Subscribe All)」，已订阅页面支持拖拽层序。 |

## 六、 实施与原型计划

1. **样式主题隔离**：可在现有样机中增加一个 **Steam Community 主题切换开关 (Steam Hub Mode)**，一键在「官方极简工作台」与「Steam 社区工坊」两套界面范式之间无缝切换；
2. **Steam 导航与组件库封装**：
   - `SteamAppHeader`（包含 App 图标、多 Tab 导航与工坊搜索）；
   - `SteamSpotlightCarousel`（大图轮播与右侧订阅盒）；
   - `SteamItemCard`（经典 16:9 蓝灰卡片、绿色订阅按钮、5星条）；
   - `SteamRequiredBox`（前置依赖提示与批量订阅）。
